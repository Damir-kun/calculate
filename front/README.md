# Construction Calculator

Веб-приложение для расчёта строительных конструкций с возможностью регистрации, авторизации и сохранения результатов.

## Требования

- Node.js 14+ 
- npm 6+

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd construction-calculator
```

2. Установите зависимости:
```bash
npm install
```

## Запуск

Для запуска в режиме разработки:
```bash
npm run dev
```

Для сборки проекта:
```bash
npm run build
```

## Функциональность

- Регистрация и авторизация пользователей
- Создание и сохранение расчётов
- Выполнение расчётов различных строительных конструкций
- Визуализация результатов с помощью SVG
- Разделение прав доступа (администратор, менеджер, пользователь)
- Управление материалами и ценами (для администраторов и менеджеров)

## Технологии
