# Инструкция по развертыванию API

## Локальное развертывание

1. **Клонирование репозитория**:
   ```bash
   git clone <repository-url>
   cd <repository-directory>
   ```

2. **Установка зависимостей**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Linux/Mac
   # или
   venv\Scripts\activate  # Для Windows
   pip install -r requirements.txt
   ```

3. **Настройка переменных окружения**:
   - Скопируйте файл `.env.example` в `.env`
   - Настройте переменные окружения в соответствии с вашей средой

4. **Запуск сервера**:
   ```bash
   python run.py
   ```

5. **Проверка работоспособности**:
   - Откройте http://localhost:8001/api/v1/health в браузере
   - Должен вернуться JSON с информацией о статусе API

## Интеграция с Frontend

### Настройка CORS

API настроен для работы с frontend на следующих доменах:
- http://localhost:3000
- http://localhost:5173

Если ваш frontend работает на другом домене, добавьте его в переменную `CORS_ORIGINS` в файле `.env`.

### Аутентификация

1. **Регистрация пользователя**:
   - Отправьте POST запрос на `/api/v1/register`
   - Получите ответ с информацией о созданном пользователе

2. **Вход в систему**:
   - Отправьте POST запрос на `/api/v1/login`
   - Получите JWT токен в ответе
   - Используйте этот токен для всех последующих запросов

3. **Использование токена**:
   - Добавьте заголовок `Authorization: Bearer <token>` к каждому запросу
   - Токен действителен в течение 1 часа

### Сохранение результатов расчетов

1. **Выполнение расчетов**:
   - Все расчеты выполняются на стороне frontend
   - Используйте JavaScript для выполнения необходимых вычислений

2. **Сохранение результатов**:
   - Отправьте POST запрос на `/api/v1/calculate` с результатами расчета
   - Включите входные параметры, результаты и дополнительную информацию
   - Пример запроса доступен в файле `API_EXAMPLES.md`

3. **Получение истории расчетов**:
   - Отправьте GET запрос на `/api/v1/history`
   - Получите список всех сохраненных расчетов пользователя

### Обработка ошибок

API возвращает ошибки в формате:
```json
{
  "detail": "Сообщение об ошибке"
}
```

Коды ошибок:
- 400: Неверный запрос
- 401: Не авторизован
- 403: Доступ запрещен
- 404: Ресурс не найден
- 409: Конфликт (например, email уже зарегистрирован)
- 500: Внутренняя ошибка сервера
